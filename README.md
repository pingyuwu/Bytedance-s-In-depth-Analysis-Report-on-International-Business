**核心摘要**
字节跳动正经历从"中国流量公司"向"全球科技帝国"的关键跃迁。2026年上半年，海外收入占集团比重已突破30%，TikTok在全球短视频市场占据约40%份额，TikTok Shop 2025年全球GMV达643亿美元、2026年上半年已达503亿美元。然而，地缘政治博弈（美国"分家法案"）、欧盟监管重锤（5.3亿欧元罚款+DSA违规初裁）、以及国内增长见顶三重压力，使字节的全球化之路充满变数。本报告从业务进展、核心挑战、竞争格局、未来预测四个维度系统拆解字节跳动国际化全貌。
